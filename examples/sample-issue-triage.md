# Sample Issue Triage

## Input

> The command crashes when I run it with my config file.

## Classification

Type: Bug report  
Priority: Medium  
Suggested labels: `bug`, `needs-repro`, `needs-info`  
Reproducible: No, the report does not include enough information.

## Missing Information

- Project version
- Operating system and runtime version
- The command that was run
- A minimal redacted configuration file
- Full error output or stack trace

## Maintainer Response Draft

Thanks for reporting this. Could you share the project version, operating system, command, full error output, and a minimal redacted config that reproduces the crash? That will help us isolate the failure without exposing credentials or private data.
