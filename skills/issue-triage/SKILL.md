# Issue Triage JA

Use this skill when triaging issues for an open-source project.

## Triage Goals

- Classify the issue type.
- Identify missing information.
- Suggest labels.
- Estimate priority.
- Draft a short maintainer response in Japanese.

## Output Format

```text
## Classification

Type:
Priority:
Suggested labels:

## Missing Information

## Maintainer Response Draft
```

## Label Suggestions

Use common labels when possible:

- bug
- enhancement
- documentation
- question
- needs-repro
- needs-info
- good-first-issue
- help-wanted
