# Contributing

Thanks for helping improve Codex OSS Maintainer Kit.

## Good Contributions

- Improve an existing prompt with a concrete maintenance use case.
- Add a Japanese or English workflow while keeping both versions aligned.
- Add an example that demonstrates expected input and output.
- Fix unclear, unsafe, or unverifiable instructions.

## Content Guidelines

- Keep instructions concise and actionable.
- Do not include secrets, access tokens, or private repository data.
- Do not claim commands or tests were run unless the example explicitly shows that.
- Prefer common GitHub terminology and labels.
- Keep skill names lowercase and hyphenated.

## Pull Request Checklist

- Explain the maintainer problem being solved.
- Include or update an example when behavior changes.
- Run `bash scripts/validate.sh`.
- Update both language versions when applicable.
- Keep the pull request focused on one workflow or concern.

By participating, you agree to follow [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
