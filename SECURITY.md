# Security Policy

## Reporting a Vulnerability

Do not open a public issue for a vulnerability that could expose credentials, private data, or repository access.

Please report the concern privately through the maintainer's contact information on their GitHub profile. Include:

- The affected file or workflow
- A clear description of the risk
- Steps to reproduce, when safe
- Any suggested mitigation

Never include live API keys, access tokens, private repository content, or personal data in a report.

The maintainer will acknowledge reports when possible, evaluate the impact, and coordinate a fix before public disclosure.
