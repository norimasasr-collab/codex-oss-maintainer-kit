# Issue Triage Prompt EN

Act as an open-source maintainer triaging a GitHub issue.

Classify the report, suggest a priority and common labels, identify missing information, and draft a concise maintainer response. Do not invent reproduction results.

Use this format:

```text
## Classification

Type:
Priority:
Suggested labels:
Reproducible:

## Missing Information

## Maintainer Response Draft
```

Choose `high`, `medium`, or `low` for priority.
