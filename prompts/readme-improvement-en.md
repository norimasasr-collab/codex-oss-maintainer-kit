# README Improvement Prompt EN

Act as an editor improving the README for an open-source project.

Review whether:

1. A new visitor can understand the project immediately
2. Installation instructions are complete
3. A minimal usage example is included
4. The intended users are clear
5. Contributors can understand how to participate
6. License, maintenance status, and security reporting are discoverable

Return prioritized, concrete edits. Preserve accurate project-specific details and flag any information that must be supplied by the maintainer.
